# Sprint 0 — Organização e planejamento

**Período:** 26/08/2026 – 01/09/2026

## Objetivo

Preparar o projeto, definir o escopo e garantir que a equipe tenha as bases necessárias para iniciar o desenvolvimento do compilador.

## Atividades planejadas

- Definir escopo do compilador;
- Definir subconjunto de Python suportado;
- Definir funcionalidades fora do escopo;
- Definir arquitetura do compilador;
- Definir fluxo Python → C;
- Configurar ambiente de desenvolvimento;
- Instalar Flex, Bison, GCC e Make;
- Criar estrutura inicial do projeto;
- Criar GitHub Project;
- Criar labels, milestones e issues;
- Definir responsabilidades;
- Definir padrões de commit e branches;
- Documentar decisões iniciais.

## Atividades concluídas

- Estrutura base do repositório organizada;
- Definição inicial do fluxo do compilador;
- Configuração do ambiente de documentação com MkDocs;
- Criação da organização inicial da documentação do projeto.

## Problemas e impedimentos

- Necessidade de alinhar a arquitetura antes da implementação;
- Definição do escopo do compilador em um nível apropriado para a disciplina.

## Decisões técnicas

- O compilador será desenvolvido em etapas por sprints semanais;
- A linguagem alvo será C;
- A arquitetura seguirá a lógica de análise léxica, sintática, semântica e geração de código.

## Resultado da Sprint

A equipe ficou preparada para começar a implementação da etapa de análise léxica.
