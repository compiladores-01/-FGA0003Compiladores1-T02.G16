**Período:** 07/10/2026 – 13/10/2026

## Objetivo

Implementar a geração de código C a partir da AST.

## Atividades planejadas

- Criar gerador de código;
- Gerar variáveis;
- Gerar números;
- Gerar strings;
- Gerar booleanos;
- Gerar `None`;
- Gerar operações matemáticas;
- Gerar comparações;
- Gerar operadores lógicos;
- Gerar atribuições;
- Gerar `print`;
- Gerar `if/else`;
- Gerar `while`;
- Gerar funções;
- Gerar `return`;
- Gerar chamadas de funções;
- Definir regras Python → C;
- Criar testes do Codegen.

## Resultado esperado

A AST deve ser convertida em código C compilável.
